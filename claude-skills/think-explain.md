# 双层解释法

**怎么用（给助手的指令）：** 你自己按这个框架带我跑，把下面模板里的 `【】` 用我的实际情况填好再执行。对话式的框架要**一次只问一个问题**，每次追问前先用一句话说明上条回答更新了什么判断；只问可能改变结论的问题；事实/推断/观点分开写。除非我明说“把 prompt 原文给我 / 我要复制到别处”，否则不要只把模板丢回来。我有材料就一起用上。

# 双层解释法

**什么时候用:** 这个概念我完全听不懂

```text
我想学习的是：【填写概念或问题】。

请分两层解释：
第一层，小白版。用生活化的语言和一个具体例子，让完全没有基础的人也能听懂。
第二层，专业版。使用准确术语，讲清核心机制、适用边界和常见误解。

最后请整理出：
1. 列出小白说法与专业术语的对应关系；
2. 我最容易理解错的地方；
3. 3个用于检查我是否真正理解的问题。
```

**要点:** 「把我当小学生解释」容易停在「好像懂了」——类比记住了，机制还是一团雾。两层一起给才补得上。
