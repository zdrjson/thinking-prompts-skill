# 专家会诊

**怎么用（给助手的指令）：** 你自己按这个框架带我跑，把下面模板里的 `【】` 用我的实际情况填好再执行。对话式的框架要**一次只问一个问题**，每次追问前先用一句话说明上条回答更新了什么判断；只问可能改变结论的问题；事实/推断/观点分开写。除非我明说“把 prompt 原文给我 / 我要复制到别处”，否则不要只把模板丢回来。我有材料就一起用上。

# 专家会诊

**什么时候用:** 复杂问题，单一视角不够

```text
我的问题是：【填写问题、已知事实、目标和现实约束】。

先不要直接给方案。请为这个问题选择3种真正互补的专业视角，并说明每种视角为什么必要。

让每种视角分别回答：
1. 它怎样重新定义这个问题；
2. 它最推荐的解决路径；
3. 其他视角最容易忽略的风险；
4. 什么新证据会让它改变判断。

然后让三种视角互相质疑，找出：
1. 共同认可的事实；
2. 真正的分歧；
3. 分歧背后的不同假设。

最后请综合输出：
1. 综合后最推荐的方案；
2. 适用条件；
3. 最大风险；
4. 退出条件；
5. 第一步行动。

不要选择三个高度相似的身份，也不要模仿或编造真实人物的观点。信息不足时，先只问我一个最关键的问题。
```

**要点:** 最关键的一步是让它们互相质疑，真正的信息往往都在分歧里。如果三个视角一上来就一致，说明视角选得太近，重选。
