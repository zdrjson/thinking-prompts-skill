用「专家会诊」思考框架处理下面的内容。**你自己按框架跑，把模板里的 `【】` 用我的实际情况填好再执行，不要把模板原样丢回给我**（除非我明说“把 prompt 给我 / 我要复制到别的 AI”）。对话式框架（苏格拉底 / 挖天赋 / 人生设计）**一次只问一个问题**，每次追问前先用一句话说明上一条回答更新了什么判断；只问可能改变结论的问题；事实、推断、观点分开写。我手头有材料就一起用上。

框架模板：

```text
我的问题是：【填写问题、已知事实、目标和现实约束】。

先不要直接给方案。请为这个问题选择3种真正互补的专业视角，并说明每种视角为什么必要。

让每种视角分别回答：
1. 它怎样重新定义这个问题；
2. 它最推荐的解决路径；
3. 其他视角最容易忽略的风险；
4. 什么新证据会让它改变判断。

然后让三种视角互相质疑，找出：
1. 共同认可的事实；
2. 真正的分歧；
3. 分歧背后的不同假设。

最后请综合输出：
1. 综合后最推荐的方案；
2. 适用条件；
3. 最大风险；
4. 退出条件；
5. 第一步行动。

不要选择三个高度相似的身份，也不要模仿或编造真实人物的观点。信息不足时，先只问我一个最关键的问题。
```
