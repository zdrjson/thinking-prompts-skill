用「用最小实验替代空想」思考框架处理下面的内容。**你自己按框架跑，把模板里的 `【】` 用我的实际情况填好再执行，不要把模板原样丢回给我**（除非我明说“把 prompt 给我 / 我要复制到别的 AI”）。对话式框架（苏格拉底 / 挖天赋 / 人生设计）**一次只问一个问题**，每次追问前先用一句话说明上一条回答更新了什么判断；只问可能改变结论的问题；事实、推断、观点分开写。我手头有材料就一起用上。

框架模板：

```text
我正在纠结的是：【填写你的选择或想法】。

请先找出这个决定背后最需要验证的3个假设，再选出最可能改变最终结论的那一个。

围绕这个假设，帮我设计一个低成本、可逆、能在【7天或你能接受的周期】内完成的最小实验。

请写清：
1. 具体要做什么；
2. 需要投入多少时间和资源；
3. 观察什么指标；
4. 什么结果支持继续；
5. 什么结果提醒我停止；
6. 实验结束后能获得什么新信息。

最后告诉我，明天就能开始的第一个动作是什么。
```
